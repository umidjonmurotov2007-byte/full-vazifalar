# AI Model Comparison Lab

## Ishga tushirish

1. Python 3.10 yoki undan yangi versiyasini o‘rnating.
2. Terminalda loyiha papkasiga kiring.
3. Kutubxonalarni o‘rnating:

```bash
pip install -r requirements.txt
```

4. Saytni ishga tushiring:

```bash
streamlit run app.py
```

5. Brauzerda Streamlit ko‘rsatgan manzilni oching (odatda http://localhost:8501).

Dataset UCI repository'dan `fetch_ucirepo(id=350)` orqali olinadi. Birinchi ishga tushirishda internet kerak.
